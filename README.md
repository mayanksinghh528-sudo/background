🏔️ Mountain Website

📌 Project Description
This is a simple HTML and CSS project that displays a mountain background image with a heading and a short description. It demonstrates basic web design using HTML and CSS.

✨ Features
- Mountain background image.
- Full-screen background using CSS.
- Centered heading and text.
- Transparent background box.
- Simple and clean design.

🛠️ Technologies Used
- **HTML5** – To create the structure of the webpage.
- **CSS3** – To style the webpage and set the background image.

📂 Project Structure

```text
Mountain-Website/
│
├── index.html
├── 6.PNG
└── README.md
```

🚀 How to Run the Project

1. Download or clone this repository.
2. Make sure `index.html` and `6.PNG` are in the same folder.
3. Open `index.html` in your web browser.
4. Enjoy your mountain background website!

💻 Code Overview

HTML
HTML is used to create the webpage structure, including the heading **"Mountain"** and the description **"This is a very beautiful Mountain."**

 CSS
CSS is used to:
- Set the mountain image as the background.
- Adjust the background image size using `background-size: cover`.
- Center the content using text alignment.
- Style the heading and description.
- Add transparency to the content box.

🎯 Purpose
The purpose of this project is to practice basic HTML and CSS concepts, including background images, font sizes, margins, and styling.
